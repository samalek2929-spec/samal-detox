# Цены в рублях и долларах

Цена в тенге вписана в страницы вручную и задана в `scripts/update-prices.mjs` (`KZT`). Рубли и доллары считаются автоматически.

Каждый день в 09:05 по Алматы GitHub Actions (`.github/workflows/update-prices.yml`) берёт официальный курс Нацбанка Казахстана, считает цены с запасом 3% (рубли до 100, доллары до 5) и обновляет `prices.json`. Страницы программ подставляют эти числа через `assets/prices.js`. Параметры должны совпадать с настройками Telegram-бота.

**Не удалять при правках страниц программ:**
- атрибут `data-price="..."` у блока `.price-main`
- строку `<script src="../assets/prices.js" defer></script>` перед `</body>`

Если поменялась цена в тенге, правится `KZT` в скрипте, число в `.price-main` и цена в настройках бота. Ручной запуск: вкладка Actions, Update prices, Run workflow.
