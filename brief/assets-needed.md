## Фото и видео

- **Реальные фотографии Самал** (портрет и/или в процессе работы) — для `about.html`, в перспективе может заменить сгенерированный портрет в hero. Текущий портрет на главной — ИИ-генерация по референсам, одобрена пользователем как временная, не документальная.
- **Скриншоты переписок / видео-отзывы** — для тизера на главной и `reviews.html`. Сейчас там честная заглушка «отзывы собираются», без придуманных цитат.
- **Фото ДО/ПОСЛЕ** — для `reviews.html`. Подать сдержанно: без стрелок, без подписей «−5 кг» (уже оговорено в брифе).
- **Фото упаковки сборов** (зелёный №1 / белый №2) — для `programs/cleanse-3.html`. Не обязательно, но реальное фото усилит доверие к составу; сейчас страница обходится текстовым списком ингредиентов.
- **Логотип** — не получен. Сейчас в шапке везде текстовый wordmark «Samal Detox».
- **Фото/видео с выездных групп или площадок** — для `group-programs.html`, желательно, не обязательно.

## Контент и тексты

- **11 вопросов с ответами** для `faq.html`, и 3 из них — для тизера на главной. Сейчас на главной честная заглушка.
- **Симптомы/состояния для 3-дневного очищения** — в брифе для тюбажа был список, для cleanse-3 такого списка не было. Страница `cleanse-3.html` сейчас использует только общее описание программы вместо списка симптомов — если у Самал есть типичный запрос клиентов для этой программы, лучше добавить для единообразия с тюбажем.

- **Материалы лид-магнита** (кандидат — недельный противоотёчный марафон) — заказчица снимает заново, место под блок предусмотрено, контентом не наполнено. Нужно также решить, где именно разместить блок (обсуждали — решили вернуться к этому позже).

- **Заявленный результат для Голодание 7/7 и 14/14** — для тюбажа и 3-дневного очищения в брифе были цифры (до 2,5 кг / до 5 кг), для голодания цифр не было. Страницы сейчас честно объясняют, что результат индивидуален и цифр не приводим — если у Самал есть подтверждённые данные, можно добавить по тому же образцу.
